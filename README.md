I got tired of refreshing a dozen sites and falling for fake "it's out!" posts, so I built a small tracker: **https://ps5jbwatcher.com**

**What it does**
- Checks 45 sources every minute: Wololo, PSXHAX, GBAtemp, Hacker News, Lemmy, Mastodon, Bing News and the GitHub releases of etaHEN, kstuff, Y2JB, elfldr and others
- **Only turns green for confirmed releases** – a GitHub release of a known scene project or an article on Wololo/PSXHAX
- Unconfirmed claims from social media are kept separate as **rumors**
- **GTA 6 → PC panel:** follows recomp, port, emulation and leak reports, plus live GitHub stats for AnyPS5, KytyPS5 and sharpemu
- Repos with lots of stars but almost no code are flagged as **likely fake**
- Optional browser notifications while the tab is open, English and German

**What it doesn't do**
No downloads, no ads, no accounts. It only links to the original sources.

The classification is keyword-based, so it can be wrong – feedback and source suggestions are very welcome!
